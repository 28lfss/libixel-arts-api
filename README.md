# Libixel Arts

Backend API for a 32x32 pixel art social platform.

## Features

- User authentication
- Pixel art publishing
- Paginated feed
- Structured pixel storage

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Docker Compose

## How To Run

- Start database with docker compose
```declarative
docker compose up -d
```

- Run application
```java
./gradlew bootRun
```
